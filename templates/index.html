    Installation Meek
    Qu'est-ce que Meek ?

    Meek est un transport pluggable qui utilise HTTP pour masquer le trafic TOR, le faisant ressembler à du trafic web normal.

    Installation
    1. Installer TOR Browser ou obfs4proxy
    2. Dans torrc, ajouter :
      UseBridges 1
      Bridge meek_lite 0.0.2.0:1 url=https://meek.azureedge.net/ front=ajax.aspnetcdn.com
    3. Redémarrer TOR
    Installation Snowflake
    Qu'est-ce que Snowflake ?

    Snowflake est un transport pluggable qui utilise des proxies temporaires fournis par des volontaires pour contourner la censure.

    Installation
    1. Installer TOR Browser ou snowflake-client
    2. Dans torrc, ajouter :
      UseBridges 1
      ClientTransportPlugin snowflake exec /usr/bin/snowflake-client
    3. Ajouter un bridge Snowflake (disponible sur torproject.org)
    4. Redémarrer TOR

    Timing Patterns
    • Fibonacci: Balanced pattern, good for evading ML-based detection
    • Sine: Smooth wave pattern, appears more organic
    • Prime: Irregular prime number intervals
    • Exponential: Gradually escalating delays
    • Random: Chaotic, unpredictable timing
    Protocol Mimicry

    Adds legitimate protocol payloads (HTTP requests, TLS ClientHello, DNS queries) to scan packets, making them appear as normal traffic.

    Realistic TCP Options

    Uses OS-specific TCP options (MSS, Window Scale, SACK, Timestamps) to avoid fingerprint detection by AI-powered firewalls.

    Fake Uptime

    Generates TCP timestamps that simulate a specific system uptime, adding legitimacy to packets.
